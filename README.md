# Grim Whispers

เซิร์ฟเวอร์กลางและเว็บคนดูสำหรับระบบ "เสียงกระซิบแห่งห้วงลึก" ใช้คู่กับโมดูล Grim Sanity ใน Foundry

คนดูเปิดเว็บจากมือถือ เลือกฝ่ายความมืดหรือแสงสว่าง กดเติมเกจฝ่ายตัวเอง โหวตการ์ดเมื่อเกจเต็ม และคนที่ส่งแรงมากที่สุดได้ทอยเต๋า Trauma สู้กับผู้เล่น

## รุ่น 0.2.0 มีอะไรบ้าง

- เกจสองฝ่าย ขนาดเท่ากัน ปรับขนาดได้ และถ่วงดุลให้ฝ่ายคนน้อยกดได้แต้มมากกว่า
- แรงกดของคนดู ปรับจำนวนที่เก็บได้และเวลาคืนแต้มได้
- โหวตการ์ด 3 ใบ เฉพาะฝ่ายที่เกจเต็ม แล้วผู้กระซิบเอกทอยเต๋า Trauma
- พร 20 ใบ แบ่งระดับ 1 ถึง 3 และหมวดซีน (Travel, Combat, Social, Camp)
- มอบสิทธิ์เลือกการ์ดหรือพรระดับ 1 ถึง 3 ให้คนดูรายคน เช่น คนที่โดเนท
- ล็อกอินด้วย Google (เปิดใช้เมื่อตั้งค่า `GOOGLE_CLIENT_ID`)
- หน้าหลอดเกจสำหรับ OBS ที่ `/overlay`
- หน้าควบคุมของ DM: ล็อกเกจ เริ่มโหวต เลือกซีน เปิดปิดการ์ด ปรับจังหวะ ค้นหาและแบนคนดู

ยังไม่มีในรุ่นนี้: เดิมพันกับความมืด, อ่านยอดโดเนทจาก YouTube อัตโนมัติ, ปุ่มส่องแสง และการเชื่อมตรงกับ Foundry

## รันบนเครื่องตัวเอง

ต้องมี Node.js 18 ขึ้นไป

```
npm install
GM_KEY=ตั้งรหัสของคุณเอง npm start
```

บน Windows (PowerShell):

```
npm install
$env:GM_KEY="ตั้งรหัสของคุณเอง"; npm start
```

- คนดู: `http://localhost:3000/`
- DM: `http://localhost:3000/dm#key=รหัสของคุณ`

ถ้าไม่ตั้ง `GM_KEY` เซิร์ฟเวอร์จะสุ่มรหัสให้และพิมพ์ไว้ตอนเริ่ม

## ให้คนดูเข้าได้จากอินเทอร์เน็ต

เลือกทางใดทางหนึ่ง

1. **โฮสต์ที่รัน Node ได้** เช่น Render, Railway หรือ Fly.io: ชี้ไปที่ repo นี้ ตั้งคำสั่งเริ่มเป็น `npm start` และตั้งตัวแปร `GM_KEY` โฮสต์ต้องรองรับ WebSocket และควรรันเครื่องเดียว เพราะสถานะอยู่ในหน่วยความจำ
2. **รันบนเครื่องตัวเองแล้วเปิดอุโมงค์** เช่น Cloudflare Tunnel: รันเซิร์ฟเวอร์ตามด้านบน แล้วให้อุโมงค์ชี้มาที่พอร์ต 3000

ทั้งสองทางต้องเป็น `https` เพื่อให้มือถือเชื่อมต่อได้

## ตัวแปร

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
| --- | --- | --- |
| `PORT` | 3000 | พอร์ตที่เปิดรับ |
| `GM_KEY` | สุ่มใหม่ทุกครั้ง | รหัสของหน้า DM อย่าใส่ในที่ที่คนดูเห็น |
| `DATA_FILE` | `data/state.json` | ไฟล์บันทึกสถานะ |
| `GOOGLE_CLIENT_ID` | ไม่ตั้ง | ใส่แล้วคนดูต้องล็อกอิน Google ก่อนเข้าร่วม |
| `ALLOW_GUESTS` | ไม่ตั้ง | ตั้งเป็น `1` เพื่อให้เข้าแบบใส่ชื่อเฉย ๆ ได้ด้วย แม้เปิด Google ไว้ |
| `SESSION_SECRET` | สร้างเองแล้วเก็บในโฟลเดอร์ data | ใช้เซ็นรหัสประจำตัวของคนดู |

## เปิดล็อกอินด้วย Google

ต้องทำในบัญชี Google ของคุณเอง ขั้นตอนโดยรวม (เมนูของ Google อาจเปลี่ยนชื่อได้):

1. เข้า Google Cloud Console สร้างโปรเจกต์ใหม่
2. ไปที่ APIs & Services แล้วตั้งค่า OAuth consent screen: เลือกแบบ External ใส่ชื่อแอปและอีเมลติดต่อ แล้วเผยแพร่แอป ระบบนี้ขอแค่ข้อมูลพื้นฐาน (ชื่อ) จึงไม่ต้องส่งให้ Google ตรวจ
3. ไปที่ Credentials กด Create credentials เลือก OAuth client ID ชนิด Web application
4. ในช่อง Authorized JavaScript origins ใส่ที่อยู่เว็บของคุณให้ตรงทุกตัวอักษร เช่น `https://whispers.example.com` ถ้าจะลองบนเครื่องให้เพิ่ม `http://localhost:3000` และ `http://localhost`
5. คัดลอก Client ID มาตั้งเป็นตัวแปร `GOOGLE_CLIENT_ID` แล้วรีสตาร์ตเซิร์ฟเวอร์

เมื่อเปิดแล้ว หนึ่งบัญชี Google นับเป็นหนึ่งคนดู เซิร์ฟเวอร์เก็บแค่ชื่อที่แสดงกับรหัสที่แปลงจากบัญชีแล้ว ไม่เก็บอีเมล เซิร์ฟเวอร์ต้องออกอินเทอร์เน็ตได้เพื่อดึงกุญแจตรวจสอบจาก Google

## หลอดเกจใน OBS

เพิ่ม Browser Source ใน OBS แล้วใส่ที่อยู่ `https://เว็บของคุณ/overlay` ตั้งขนาดเช่น 1920 x 300 พื้นหลังโปร่งใส หลอดจะขยับทุกครั้งที่มีคนกด

ตัวเลือกต่อท้ายที่อยู่:

| ตัวเลือก | ผล |
| --- | --- |
| `?show=gauges` | แสดงแค่หลอด ไม่แสดงแถบโหวตและผลทอย |
| `?side=dark` หรือ `?side=light` | แสดงหลอดฝ่ายเดียว |
| `?scale=1.5` | ขยายหรือย่อ |
| `?align=top` | ชิดขอบบนแทนขอบล่าง |

ใส่หลายตัวพร้อมกันได้ เช่น `/overlay?show=gauges&scale=1.3`

## มอบสิทธิ์ให้คนดูรายคน

ในช่อง Viewers ของหน้า DM พิมพ์ชื่อเพื่อค้นหา แล้วกดเลข 1, 2 หรือ 3 ข้างชื่อ คนดูคนนั้นจะได้เลือกการ์ด (ถ้าอยู่ฝ่ายความมืด) หรือพร (ถ้าอยู่ฝ่ายแสงสว่าง) ระดับนั้นหนึ่งใบบนมือถือ สิ่งที่เลือกจะมารอในช่อง Viewer picks ให้ DM กด Play เมื่อถึงจังหวะ

- การเล่นสิทธิ์นี้ไม่กระทบเกจและจำนวนครั้งที่เกจเต็ม
- ฝ่ายความมืด: คนที่ได้สิทธิ์เป็นคนทอยเต๋า Trauma ลูกแรก
- ตัวเลือกมาจากการ์ดที่เปิดอยู่ในซีนตอนนั้น เพดานระดับที่ DM ตั้งไว้ไม่ตัดสิทธิ์ระดับที่มอบให้
- ตัวอย่างที่ใช้ได้: โดเนท 100 บาทได้ระดับ 1, 300 บาทได้ระดับ 2, 500 บาทได้ระดับ 3 ระบบไม่ได้อ่านยอดโดเนทเอง DM เป็นคนกดให้

## ลำดับใช้งานในไลฟ์

1. เปิดหน้า DM กด **New stream** ถ้าเป็นไลฟ์ใหม่
2. แปะลิงก์คนดูในแชตหรือคำอธิบายไลฟ์
3. เลือกซีนในช่อง **Scene** (ตั้งทั้งการ์ดและพรพร้อมกัน) พอซีนแรกจบ กด **Unlock both**
4. เกจฝ่ายไหนเต็ม เล่นจังหวะที่ค้างอยู่ให้จบ แล้วกด **Start vote** ของฝ่ายนั้น
5. ฝ่ายความมืด: รอผลทอย กด **Copy Foundry macro** วางเป็น script macro ใน Foundry แล้วรัน จะเปิดการดวลด้วยการ์ดและแต้มที่คนดูทอย
6. ฝ่ายแสงสว่าง: มอบพรจากแท็บ Light ของ Grim Sanity
7. กด **Done · clear** เพื่อกลับไปเติมเกจต่อ

## ปรับจังหวะและการถ่วงดุล

ทั้งหมดอยู่ในช่อง Pacing ของหน้า DM เปลี่ยนได้ระหว่างไลฟ์

| ช่อง | ความหมาย | ค่าเริ่มต้น |
| --- | --- | --- |
| Gauge size | ขนาดเกจขั้นต่ำ สองฝ่ายใช้ขนาดเดียวกัน | 20 |
| Extra size per viewer | เกจจะโตเป็น (จำนวนคนของฝ่ายที่มากกว่า x ค่านี้) ถ้ามากกว่าขนาดขั้นต่ำ ใส่ 0 เพื่อให้เกจคงที่ตาม Gauge size | 20 |
| Presses a viewer can hold | แรงกดที่คนดูเก็บได้สูงสุด | 5 |
| One press returns every | กี่วินาทีได้แรงกดคืน 1 แต้ม | 30 |
| Each fill makes the next larger by | เกจเต็มแล้วรอบถัดไปใหญ่ขึ้นกี่เปอร์เซ็นต์ | 25 |
| Balance the sides | ฝ่ายคนน้อยกดหนึ่งครั้งได้แต้มมากขึ้นตามสัดส่วน | เปิด |
| Most one press can be worth | เพดานของแต้มต่อการกดหนึ่งครั้ง | 5 |

ตัวอย่างการถ่วงดุล: ความมืด 10 คน แสงสว่าง 3 คน ฝ่ายแสงสว่างกดครั้งละ 3.3 แต้ม ถ้าทุกคนกดเท่ากัน สองเกจจะขึ้นเร็วพอกัน

ถ้าเกจเต็มเร็วกว่า 15 นาทีให้เพิ่มขนาด ช้ากว่า 40 นาทีให้ลด

## โครงสร้าง

- `server/engine.js` กติกาทั้งหมด ไม่มีโค้ดเครือข่าย
- `server/index.js` HTTP และ WebSocket
- `shared/cards.js` การ์ดชุดเดียวกับโมดูล Grim Sanity
- `server/google.js` ตรวจการล็อกอินด้วย Google
- `public/` เว็บคนดู (`index.html`), หน้า DM (`dm.html`) และหลอดเกจ OBS (`overlay.html`)
